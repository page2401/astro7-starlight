03. 数学公式排版（LaTeX Math）

Astro 7 + Starlight 本身未内置公式开关，且 Astro 7 将默认 Markdown 解析器切换为 Sätteri 后不再默认附带 unified 管线——因此除了在 astro.config.mjs 中挂载 remark-math@6.0.0 与 rehype-katex@7.0.1 并在 customCss 引入 katex.min.css 外，还必须显式安装 @astrojs/markdown-remark@7.3.10。所有公式在构建期直接编译为 KaTeX HTML + CSS Webfont 结构。

1. 行内公式与中英文混排基线对齐

Section titled “1. 行内公式与中英文混排基线对齐”

考察重点：行内公式在中文字号下的缩放比例、上下标是否撑乱行高，以及分数与根号在行内的紧凑度。

5. 字面量美元符号 \$ 转义边界测试

Section titled “5. 字面量美元符号 \$ 转义边界测试”

在启用 $...$ 行内数学公式后，同一段落出现两个价格数字（例如基础套餐 $29/月 与专业版 $99/月）时，若未正确转义 \$ 会把中间的中文误解析为斜体公式；而在反引号代码片段中编写环境变量 $HOME 或 awk '{print $1}' 则应原样保留，无需反斜杠转义。
