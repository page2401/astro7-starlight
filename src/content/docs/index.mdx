## 子模块版本档案

本站点由独立仓库 [`page2401/astro7-starlight`](https://github.com/page2401/astro7-starlight) 构建，`main` 分支仅保存纯源代码与适配后的 `*.md` 基准文档，GitHub Actions 在每次推送后自动编译并发布至孤儿分支 `page`。

| 依赖模块 | 精确锁定版本 | 在本子站中的职责 |
| :--- | :--- | :--- |
| `astro` | `7.4.13` | 核心静态站点构建引擎（Node 22 + Content Layer API + Sätteri） |
| `@astrojs/starlight` | `0.43.1` | 官方文档主题集成（内置 `astro-expressive-code` 与 Pagefind 搜索） |
| `@astrojs/markdown-remark` | `7.3.10` | Astro 7 默认改用 Sätteri 后，运行 unified/remark 插件须显式安装此包 |
| `remark-math` / `rehype-katex` | `6.0.0` / `7.0.1` | Markdown 数学语法解析与 KaTeX HTML 结构生成 |
| `katex` | `0.19.1` | 数学排版样式表与 Webfont 字体资源 |
| `mermaid` | `12.3.0` | 最新第 12 代客户端流程图、时序图与状态机渲染引擎 |
